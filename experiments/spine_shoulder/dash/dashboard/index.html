SHOULDER ASYMMETRY BUG FIXED. The mobile (ellipsoid) scapula was moving asymmetrically under symmetric commands ('bobbing', 'left popped off'). Root cause was mine: converting the welded scapula to an EllipsoidJoint, I mirrored the joint's parent-frame TRANSLATION directly, but the ellipsoid bakes a (0,0,semi_z) surface offset along that frame so the translation is NOT mirror-symmetric — the left scapula ended 0.15 m off. Fix: compute the left translation from the mirrored TARGET position, t_l = M@p0 - R0l@semi. Confirmed the source model was already perfectly symmetric, so this was not the prior symmetrization.
